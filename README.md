# 🌌 Общее описание

Современные информационные системы представляют собой сложные динамические сети, в которых распространение контента определяется не только структурой связей между пользователями, но и:

- эмоциональным состоянием участников;
- когнитивными особенностями;
- уровнем доверия;
- манипулятивными воздействиями;
- активностью автоматизированных агентов;
- алгоритмами искусственного интеллекта.

Данный проект реализует **исследовательскую платформу** для моделирования подобных процессов в виде мультиагентной системы.

---

# 🧠 Ключевая идея

Каждый пользователь сети моделируется как автономный агент, обладающий:

| Параметр | Интерпретация |
|---|---|
| `b` | убеждения / bias |
| `c` | устойчивость взглядов |
| `e` | эмоциональное состояние |

Поведение агента определяется:

- согласованностью сообщения с его взглядами;
- эмоциональной нагрузкой контента;
- силой социальных связей;
- текущим эмоциональным состоянием.

## 7.2 ⚙️ Параметры симуляции

Параметры определяют длительность симуляции, скорость затухания информации и жизненный цикл сообщений внутри сети.

<div align="center">

| 🧩 Параметр | 🔢 Значение по умолчанию | 📖 Описание |
|---|---|---|
| `T_steps` | `4` | Количество временных шагов симуляции |
| `decay` | `0.85` | Коэффициент затухания вероятности распространения сообщений |
| `max_age` | `5` | Максимальный возраст сообщения до удаления из процесса диффузии |

</div>

---

### 🕒 `T_steps`

Определяет количество итераций симуляции.

На каждом шаге:

- агенты получают сообщения;
- вычисляется вероятность репоста;
- обновляются состояния пользователей;
- Blue Agent анализирует новые сообщения;
- обновляется таймлайн распространения.

#### Пример

```python
T_steps = 10
```

Симуляция выполнит 10 последовательных временных итераций.

---

### 📉 `decay`

Коэффициент временного затухания информации.

Чем старше сообщение, тем ниже вероятность его дальнейшего распространения.

Используется для моделирования:

- потери актуальности контента;
- снижения интереса аудитории;
- затухания информационных волн.

#### Интерпретация значений

| Значение | Эффект |
|---|---|
| `1.0` | Сообщение не теряет актуальность |
| `0.85` | Умеренное затухание |
| `0.5` | Быстрое снижение распространения |
| `0.1` | Почти мгновенное исчезновение |

---

### ⏳ `max_age`

Максимальный возраст сообщения в шагах симуляции.

После превышения этого значения сообщение:

- удаляется из активного распространения;
- перестаёт участвовать в репостах;
- сохраняется только в истории.

#### Пример

```python
max_age = 5
```

Сообщение может распространяться максимум 5 временных шагов.

## 7.3 🔁 Параметры репоста (`RepostParams`)

Механизм репоста — центральная часть симуляции, определяющая распространение информации внутри сети.

Вероятность того, что пользователь сделает репост сообщения, вычисляется через логистическую функцию:

```text
p = sigmoid(
    lambda0 +
    lambda1 * kappa +
    lambda2 * e +
    lambda3 * h +
    lambda4 * rel
)
```

---

### 📌 Интерпретация переменных

| Переменная | Смысл |
|---|---|
| `kappa` | степень согласия пользователя с сообщением |
| `e` | эмоциональное состояние пользователя |
| `h` | эмоциональная нагрузка сообщения |
| `rel` | сила социальной связи между агентами |

---

## 🧠 Формула согласия (`kappa`)

```text
kappa = exp(-alpha * abs(b_message - b_user))
```

---

### 📖 Интерпретация

Чем ближе мнение пользователя к содержанию сообщения:

- тем выше `kappa`;
- тем выше вероятность репоста;
- тем сильнее влияние сообщения.

---

### 📊 Поведение функции

| Разница взглядов | Значение `kappa` |
|---|---|
| Очень маленькая | Близко к `1` |
| Средняя | Умеренное |
| Очень большая | Близко к `0` |

---

## 🔄 Обновление убеждений

После получения сообщения агент может изменить собственные взгляды:

```text
b_new = b + c * beta * kappa * (b_msg - b)
```

---

### 📌 Интерпретация параметров

| Переменная | Значение |
|---|---|
| `b` | текущее мнение пользователя |
| `b_msg` | мнение, выраженное в сообщении |
| `c` | устойчивость убеждений |
| `beta` | скорость изменения взглядов |
| `kappa` | уровень согласия |

---

## ⚙️ Полное описание параметров

<div align="center">

| 🧩 Параметр | 🔢 Default | 📖 Описание |
|---|---|---|
| `lambda0` | `-2.0` | Базовая склонность к репосту |
| `lambda1` | `4.0` | Влияние согласия (`kappa`) |
| `lambda2` | `2.0` | Влияние эмоционального состояния |
| `lambda3` | `2.0` | Влияние эмоциональности сообщения |
| `lambda4` | `1.0` | Влияние силы социальной связи |
| `alpha` | `3.0` | Чувствительность к различию взглядов |
| `beta` | `0.2` | Скорость обновления убеждений |

</div>

---

### 🔹 `lambda0`

Базовый уровень вероятности репоста.

Фактически определяет:

> насколько пользователи склонны распространять информацию даже без сильных стимулов.

---

#### Интерпретация

| Значение | Эффект |
|---|---|
| Очень отрицательное | Репосты происходят редко |
| Близкое к `0` | Умеренная активность |
| Положительное | Сеть становится гиперактивной |

---

### 🔹 `lambda1`

Коэффициент влияния согласия (`kappa`).

Определяет, насколько пользователи предпочитают контент, совпадающий с их взглядами.

---

#### Высокие значения

Приводят к:

- формированию echo chambers;
- поляризации;
- усилению идеологических кластеров.

---

### 🔹 `lambda2`

Влияние эмоционального состояния пользователя.

Эмоционально возбуждённые агенты:

- чаще делают репосты;
- быстрее вовлекаются в каскады;
- сильнее распространяют вирусный контент.

---

### 🔹 `lambda3`

Влияние эмоциональной нагрузки сообщения.

Высокие значения параметра моделируют среды, где:

- эмоциональный контент доминирует;
- провокационные сообщения становятся вирусными;
- дезинформация распространяется быстрее.

---

### 🔹 `lambda4`

Влияние силы социальной связи.

Чем выше доверие между пользователями:

- тем выше вероятность передачи сообщения;
- тем устойчивее локальные каскады.

---

### 🔹 `alpha`

Контролирует чувствительность к различию взглядов.

---

#### Малые значения

Пользователи терпимы к противоположным мнениям.

---

#### Большие значения

Даже небольшие различия:

- резко уменьшают `kappa`;
- усиливают сегментацию сообщества.

---

### 🔹 `beta`

Скорость изменения убеждений.

---

#### Малые значения

- пользователи устойчивы;
- мнения меняются медленно;
- каскады развиваются стабильно.

---

#### Большие значения

- взгляды быстро адаптируются;
- возникает высокая динамичность;
- возможны резкие идеологические сдвиги.

---

# 7.4 📨 Параметры генерации сообщений

Эти параметры определяют:

- как часто агенты создают новый контент;
- какие типы сообщений появляются;
- насколько активны различные категории агентов.

---

## ⚙️ Основные параметры

<div align="center">

| 🧩 Параметр | 🔢 Default | 📖 Описание |
|---|---|---|
| `prob_user_message` | `0.3` | Вероятность генерации сообщения обычным пользователем |
| `prob_llm_message` | `0.4` | Вероятность генерации сообщения LLM-агентом |
| `red_always_generates` | `True` | Красные агенты публикуют сообщения на каждом шаге |
| `category_probs` | `uniform` | Распределение категорий сообщений |

</div>

---

## 👤 `prob_user_message`

Вероятность того, что обычный пользователь создаст новое сообщение на временном шаге.

---

### Низкие значения

```python
prob_user_message = 0.1
```

- сеть становится менее активной;
- распространение определяется репостами;
- каскады возникают реже.

---

### Высокие значения

```python
prob_user_message = 0.8
```

- сеть генерирует большое количество контента;
- резко возрастает информационный шум;
- сложнее отслеживать каскады.

---

## 🤖 `prob_llm_message`

Частота генерации контента LLM-агентами.

---

### Высокие значения

Моделируют:

- AI-generated social media;
- автоматизированные сети;
- synthetic information ecosystems.

---

## 🔴 `red_always_generates`

Если установлено:

```python
True
```

то красные агенты:

- публикуют сообщения на каждом шаге;
- непрерывно поддерживают информационные атаки;
- инициируют новые каскады.

---

### Если `False`

Красные агенты начинают вести себя более реалистично и стохастически.

---

## 🧩 `category_probs`

Распределение типов сообщений для LLM-агентов.

---

### Пример

```python
category_probs = {

    "manipulative": 0.3
}
```

---

## 📌 Интерпретация

| Категория | Описание |

| `neutral` | Нейтральный контент |
| `threat` | Агрессивные или угрожающие сообщения |

# 7.5 🛡 Параметры Blue Agent (`blue_agent.py`)

Blue Agent — интеллектуальная система анализа рисков, оценивающая опасность сообщений внутри сети.

---

## 🎯 Основные задачи

- обнаружение угроз;
- оценка токсичности;
- анализ манипулятивного контента;
- вычисление глобального риска сети.

---

## ⚙️ Параметры

<div align="center">

| 🧩 Параметр | 🔢 Default | 📖 Описание |
|---|---|---|
| `model_type` | `"deberta"` | Тип используемой модели |
| `max_length` | `4096` | Максимальная длина токенизации |
| `threshold` | `0.3` | Порог выделения подозрительных фрагментов |
| `device` | `"auto"` | Устройство выполнения |
| `load_in_4bit` | `True` | Использование 4-bit quantization |
| `batch_size` | `32` | Размер batch processing |

</div>

---

## 🤖 `model_type`

Определяет модель анализа рисков.

---

### Поддерживаемые варианты

| Модель | Назначение |
|---|---|
| `deberta` | Базовый Transformer-анализ |
| `qwen` | Экспериментальный режим |

---

## 📏 `max_length`

Максимальная длина текста после токенизации.

---

### Большие значения

Позволяют анализировать:

- длинные посты;
- цепочки сообщений;
- многоступенчатые манипуляции.

---

### Минусы

- выше потребление VRAM;
- медленнее inference.

---

## 🚨 `threshold`

Порог чувствительности системы.

---

### Низкие значения

- система становится агрессивной;
- увеличивается количество false positives.

---

### Высокие значения

- снижается чувствительность;
- уменьшается количество ложных тревог.

---

## ⚡ `load_in_4bit`

Использование 4-bit quantization через:

```text
bitsandbytes
```

---

### Преимущества

- снижение использования VRAM;
- ускорение inference;
- возможность работы на consumer GPU.

---

## 📦 `batch_size`

Размер пакета сообщений при batch inference.

---

### Большие batch

- быстрее обработка;
- выше загрузка GPU.

---

### Малые batch

- стабильнее на слабых GPU;
- ниже риск OOM.

---
